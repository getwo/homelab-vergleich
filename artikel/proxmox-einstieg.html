Proxmox für Einsteiger: Der komplette Guide 2026

Wer sein Homelab selbst aufbauen will, stößt früher oder später auf Proxmox Virtual Environment — kurz Proxmox VE. Die kostenlose Open-Source-Plattform verwandelt einen einzelnen Rechner in einen kompletten Virtualisierungs-Server, auf dem mehrere virtuelle Maschinen und Container gleichzeitig laufen. Dieser Guide führt dich Schritt für Schritt durch den Einstieg: von der Installation über die erste VM bis zu den wichtigsten Netzwerk- und Fehler-Grundlagen.

Was ist Proxmox?

Proxmox VE ist ein sogenannter Typ-1-Hypervisor auf Basis von Debian Linux. Das heißt: Es läuft direkt auf der Hardware — ohne ein Windows oder Linux darunter — und verwaltet darüber Betriebssysteme als virtuelle Maschinen (VMs). Zusätzlich unterstützt Proxmox LXC-Container, die deutlich weniger Ressourcen brauchen als eine volle VM und sich besonders für einzelne Dienste wie Pi-hole, Home Assistant oder einen Webserver eignen. Verwaltet wird alles über eine übersichtliche Web-Oberfläche, die du im Browser unter der IP deines Servers erreichst. Proxmox ist kostenlos und quelloffen; optional gibt es ein Support-Abo, für den Heimgebrauch brauchst du es aber nicht.

Installation: USB-Stick, ISO, erster Boot

Die Installation ist der einfachste Teil. So gehst du vor:

  1. ISO herunterladen: Lade das aktuelle Proxmox-VE-ISO-Image von der offiziellen Website herunter.
  2. USB-Stick erstellen: Schreibe die ISO mit einem Tool wie Rufus (Windows) oder balenaEtcher auf einen USB-Stick. Ein 8-GB-Stick reicht locker.
  3. Booten: Stecke den Stick in den Server, starte ihn neu und wähle im BIOS/UEFI-Bootmenü den USB-Stick aus.
  4. Installieren: Folge dem grafischen Installer. Wichtig sind hier drei Dinge: das Ziel-Laufwerk für die Installation, ein Root-Passwort (unbedingt merken) und die Netzwerk-Konfiguration mit fester IP-Adresse.
  5. Web-Oberfläche öffnen: Nach dem Neustart erreichst du Proxmox im Browser unter https://IP-Adresse:8006.

Die Warnung zum fehlenden Zertifikat kannst du im Heimnetz getrost akzeptieren — sie entsteht, weil Proxmox ein selbstsigniertes Zertifikat mitbringt.

Die erste VM und der erste Container

Für eine virtuelle Maschine brauchst du zuerst ein Installations-Image. Lade dir zum Beispiel eine Ubuntu- oder Windows-ISO herunter und lege sie über „local“ → „ISO Images“ hoch. Danach klickst du auf „Create VM“, folgst dem Assistenten und weist der VM CPU-Kerne, RAM und Speicherplatz zu. Beim Start mountest du die ISO als CD-Laufwerk und installierst das Betriebssystem wie auf echter Hardware.

Ein Container geht noch schneller: Proxmox bringt vorgefertigte Templates mit. Unter „local“ → „CT Templates“ lädst du ein Template (etwa Debian oder Ubuntu) herunter und erstellst daraus mit wenigen Klicks einen Container. Der ist in Sekunden gestartet und verbraucht nur einen Bruchteil des Speichers einer VM.

Netzwerk-Grundlagen: vmbr0

Das Herzstück des Proxmox-Netzwerks ist die Linux Bridge vmbr0. Eine Bridge funktioniert wie ein virtueller Switch: Sie verbindet deine physische Netzwerkkarte mit den virtuellen Netzwerkkarten deiner VMs und Container. Deshalb bekommen alle Gäste ihre IP-Adressen direkt aus deinem Router — sie sind im Heimnetz genauso erreichbar wie ein echtes Gerät. Bei der Installation wird vmbr0 normalerweise automatisch angelegt und mit deiner Netzwerkkarte verbunden. Solange du nichts Besonderes vorhast, musst du daran nichts ändern. Jede neue VM und jeder Container wird einfach an vmbr0 gehängt und funktioniert sofort.

Häufige Fehler (und wie du sie vermeidest)

Diese Stolpersteine begegnen fast jedem Einsteiger irgendwann:

  • Virtualisierung nicht aktiviert: Läuft keine VM, fehlt im BIOS oft die Einstellung „Intel VT-x“ bzw. „AMD-V“. Prüfe das als Erstes.
  • IOMMU vergessen: Wer VMs später echte Hardware (z. B. eine Grafikkarte) durchreichen will, muss im BIOS auch „VT-d“ bzw. „AMD-Vi“ aktivieren.
  • Falsche Bridge gewählt: Wählst du beim Anlegen einer VM versehentlich keine Bridge, bekommt die VM kein Netzwerk. Achte darauf, dass „vmbr0“ ausgewählt ist.
  • Zu wenig RAM eingeplant: Windows-VMs brauchen mindestens 4 GB, sonst werden sie unbenutzbar. Plane Puffer ein.
  • Abo-Hinweis: Der rote Hinweis „Kein gültiges Abonnement“ ist nur kosmetisch — im Heimgebrauch kannst du ihn ignorieren.

Sinnvolle Hardware

Proxmox läuft schon auf bescheidener Hardware, aber ein paar Dinge solltest du einplanen. Die CPU sollte Virtualisierung unterstützen — praktisch jede CPU der letzten zehn Jahre tut das. RAM ist der wichtigste Faktor: Rechne mindestens 8 GB, besser 16 GB, da jede VM ihren Speicher exklusiv belegt. Für die Installation reicht eine schnelle NVMe-SSD, für Daten und Backups empfehlen sich zusätzlich große HDDs. Eine zweite Netzwerkkarte ist nur nötig, wenn du Netze sauber trennen willst — für den Start genügt eine.

Welcher Rechner sich als Proxmox-Host eignet, hängt stark von deinem Budget und Platzbedarf ab: Ein sparsamer Mini-PC ist ideal, wenn du leise und stromsparend starten willst. Wer mehr Leistung, ECC-Speicher oder viele Festplatten braucht, findet in unserem Ratgeber zu Server-Hardware fürs Homelab die passende Empfehlung.

Fazit

Proxmox ist der perfekte Einstieg in die Virtualisierung: kostenlos, stabil und mit einer Web-Oberfläche, die auch Anfänger schnell verstehen. Der Weg ist immer derselbe — ISO auf den USB-Stick, installieren, vmbr0 bestätigen, erste VM oder den ersten Container anlegen. Sobald du die Grundlagen verstanden hast, steht dir die ganze Welt des Homelabs offen: von zusätzlichen Diensten bis zu ausgewachsenen Server-Setups.
